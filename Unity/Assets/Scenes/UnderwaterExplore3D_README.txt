操作：
- W / A / S / D：沿镜头方向游动
- Space：上浮
- Left Ctrl：下潜
- Left Shift：加速
- 按住鼠标右键：旋转镜头
- 鼠标滚轮：调整镜头距离
- C：镜头回正
- F：开箱 / 长按开采生物矿；E：背包
- V：第一/第三人称；第一人称 Esc 释放鼠标、右键恢复转头。
- 鱼叉：第三人称按住右键瞄准 + 左键发射；第一人称锁定鼠标时左键发射。每发自动装填1.6秒。
- 第一图、第三图和第五图禁用 R 瞬移，需上浮撤离；第二图和第四图可用 R 复位。
